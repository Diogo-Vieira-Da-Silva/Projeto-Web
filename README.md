# Web in Focus

## Description

"Web in Focus" (Web em Foco) is an educational and accessible website covering HTML, CSS, and JavaScript. The project introduces fundamental web development concepts, features an interactive activity with automatic grading, and provides information about the developer.

## Theme

Web development fundamentals and digital accessibility features.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Pages Developed

- `index.html`: Home page featuring an introduction to the project and content highlights.
- `pages/conteudo.html`: Explanations of HTML, CSS, and JavaScript, including images and captions.
- `pages/atividades.html`: A form containing five questions based on the content, with automated feedback on results.
- `pages/perfil.html`: Personal profile, including background, interests, and the technologies used in the project.

## File Structure

- `index.html`: Home page.
- `pages/`: Internal site pages.
- `assets/css/`: Project stylesheets.
- `assets/js/`: JavaScript files (shared scripts and activity-specific logic).
- `assets/images/`: Images used throughout the site.

## How to Run

1. Download or clone the project folder.
2. Open the `index.html` file in a web browser.
3. For a local server-based experience, run an HTTP server from the project's root directory.

## Accessibility Features

All pages include controls to increase or decrease font size, enable high-contrast mode, listen to the content, and stop the text-to-speech playback.
