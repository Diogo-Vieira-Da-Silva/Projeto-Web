Fundamentos da web

HTML, CSS e JavaScript

Três tecnologias trabalham juntas para dar estrutura, apresentação e comportamento às páginas da Internet.

Estrutura com HTML

O HTML utiliza marcações semânticas para organizar títulos, textos, imagens, listas e formulários. Elementos como "header", "nav" e "main" ajudam navegadores e tecnologias assistivas a compreender o conteúdo.

Uma boa estrutura melhora a leitura, a navegação por teclado e a indexação do documento pelos mecanismos de busca.

Estilo com CSS

O CSS define cores, espaçamentos, tipografia e posição dos elementos. Com regras responsivas, o mesmo conteúdo pode ser apresentado de forma adequada em celulares, tablets e computadores.

Boas práticas incluem contraste de cores, áreas de interação visíveis e tamanho de fonte ajustável.

Interatividade com JavaScript

O JavaScript adiciona comportamento dinâmico às páginas, permitindo responder a ações do usuário, validar formulários e atualizar conteúdo sem recarregar a página.

Boas práticas incluem o uso de eventos semânticos, tratamento de erros e manutenção de código organizado.
